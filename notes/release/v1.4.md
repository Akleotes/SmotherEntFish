Smotherfish 1.4: a Stockfish-strength chess engine that plays for the smothered mate.

## What's new

- **`HumanElo`: play like a human of a given rating.** Set `HumanElo` to a
  rating from 1050 to 2500 (0 = off) and nothing else: it sets the strength
  limit and the rate of real mistakes itself. Ratings are measured against
  the human-like Maia-3 network (the Maia-3 level it scores 50% against at
  5+0.05, about +-50). For a club player of about 1350, use `HumanElo 1350`.
- **Human mode fix.** In 1.3, any `HumanBlunder` above 0 also made every
  ordinary move weaker (the choice widened from 4 to 8 candidates). Fixed,
  so `HumanBlunder` settings now play stronger than in 1.3: `HumanBlunder 1`
  is about 1735, not 1350. Use `HumanElo` instead.
- Full-strength play and smother hunting are unchanged from 1.3 (same
  search; bench 1210779).

## Which file

| File | For |
| ---- | --- |
| `smotherfish-1.4-android-arm64-dotprod` | Android phones from about 2019 on (faster) |
| `smotherfish-1.4-android-arm64` | Older Android phones |
| `smotherfish-1.4-windows-x86-64-avx2.exe` | Windows PCs from about 2015 on (faster) |
| `smotherfish-1.4-windows-x86-64.exe` | Older Windows PCs |
| `smotherfish-1.4-linux-x86-64-avx2` | Linux, CPUs from about 2015 on (faster) |
| `smotherfish-1.4-linux-x86-64` | Linux, older CPUs |

Use it in any UCI chess GUI. On Android, DroidFish: Manage chess engines,
Install, pick the file; then set `HumanElo` in the engine options for a
human-like opponent. Smother hunting is on by default.

Details: README.md and docs/SMOTHERFISH.md.
