Smotherfish 1.6: a Stockfish-strength chess engine that plays for the smothered mate.

## What's new

- **Plays for the textbook smothered mate.** A knight mates a king that its
  own pieces box in on every side. 1.5.1 aimed at any smothered mate and
  ended 0.7 games in 100 with a knight one against Stockfish Elo 1500; 1.6
  ends about 4 in 100 (2,500-game tests at 5+0.05), about 5 against the
  human-like Maia-3 1500, and at 3+2 3.7 against Stockfish 1500 and 6.3
  against Maia-3 (1.5.1: 0.9 and 1.4).
- How: `SmotherClassic` on, a construction-score bonus for a knight on its
  way to a checking square (`SmotherBuildKnightCheck 16`) and a deeper
  prover once the game is decided (`SmotherCrushMoves 16`,
  `SmotherCrushQuiet 3`). `SmotherClassic false` and the old values bring
  back 1.5.1's aim (any piece).
- No change in playing strength: -0.3 Elo against 1.5.1 over 32,400 games at
  10+0.1 (95% range -1.2 to +0.5). Bench unchanged (1210779).
- New experimental options, off by default: a learned model and a small
  neural network as the construction score (`SmotherBuildModelScale`,
  `SmotherBuildNetScale`), a "prep phase" (`SmotherPrep*`). They were
  measured and did not beat the defaults; see docs/SMOTHERFISH.md.
- Tidier option list: 29 experimental options that never beat the defaults
  were removed (the engine plays exactly as with their old defaults; list in
  docs/SMOTHERFISH.md).
- Lichess bots: no games under one minute, at most two games per bot per
  hour.
- Help test Smotherfish: fork the repository and enable its workflows
  (docs/HELPING.md). Live status: https://demonic1594.github.io/Smotherfish/

## Which file

On Android, take the `dotprod` file first (most phones from about 2019 on);
if DroidFish reports that the engine does not start, take the plain
`android-arm64` one instead. You do not need both.

| File | For |
| ---- | --- |
| `smotherfish-1.6-android-arm64-dotprod` | Android phones from about 2019 on (faster) |
| `smotherfish-1.6-android-arm64` | Older Android phones |
| `smotherfish-1.6-windows-x86-64-avx2.exe` | Windows PCs from about 2015 on (faster) |
| `smotherfish-1.6-windows-x86-64.exe` | Older Windows PCs |
| `smotherfish-1.6-linux-x86-64-avx2` | Linux, CPUs from about 2015 on (faster) |
| `smotherfish-1.6-linux-x86-64` | Linux, older CPUs |

Details: README.md and docs/SMOTHERFISH.md.
