Smotherfish 1.7: a Stockfish-strength chess engine that plays for the smothered mate.

## What's new

- **Stronger: newer Stockfish.** Stockfish's latest search and network
  (upstream commit `88337401`, network `nn-684d0e60e71d`) are merged in:
  +1.7 Elo against 1.6 over 76,000 games at 10+0.1 (95% range +1.1 to +2.3).
  Bench 1128273.
- **Same smothers.** On the same openings at 5+0.05, 1.7 ends 3.12 games in
  100 with a knight smother (all opponents pooled), 1.6 3.19: within the
  noise, no losses. Against Stockfish 1500: 3.7 (1.6: 3.7); Maia-3 1500: 3.0
  (3.6); Stockfish 2500: 1.6 (1.0).
- **HumanElo refitted.** The new engine's `UCI_Elo` limiter plays weaker at the
  same setting, so the HumanElo map was refitted and measured against 1.6 at
  1580, 1700, 1735, 1880, 2200 and 2400: each rating plays as it did in 1.6
  (600 games per point against Maia-3).
- New experimental options, off by default, each measured without a gain; see
  docs/SMOTHERFISH.md, "Experimental".

## Which file

On Android, take the `dotprod` file first (most phones from about 2019 on);
if DroidFish reports that the engine does not start, take the plain
`android-arm64` one instead. You do not need both.

| File | For |
| ---- | --- |
| `smotherfish-1.7-android-arm64-dotprod` | Android phones from about 2019 on (faster) |
| `smotherfish-1.7-android-arm64` | Older Android phones |
| `smotherfish-1.7-windows-x86-64-avx2.exe` | Windows PCs from about 2015 on (faster) |
| `smotherfish-1.7-windows-x86-64.exe` | Older Windows PCs |
| `smotherfish-1.7-linux-x86-64-avx2` | Linux, CPUs from about 2015 on (faster) |
| `smotherfish-1.7-linux-x86-64` | Linux, older CPUs |

Details: README.md and docs/SMOTHERFISH.md.
